# Create or Test Objects of Class "mcpfamily"

Create or Test Objects of Class "mcpfamily"

## Usage

``` r
mcpfamily(x)

is.mcpfamily(x)
```

## Arguments

- x:

  A family object, e.g., `binomial(link = "identity")`.

## Functions

- `is.mcpfamily()`: Checks whether x is an `mcpfamily`.
