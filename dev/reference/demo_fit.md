# Pre-fitted example mcp model

`demo_fit` is an `mcpfit` object generated using
`mcp_example("demo", sample = FALSE)`, though with two modifications: it
only has 2 x 1000 samples, and it also includes prior samples.

## Usage

``` r
demo_fit
```

## Format

An
[`mcpfit`](https://lindeloev.github.io/mcp/dev/reference/mcpfit-class.md)
object.

## Details

It is used to quickly demonstrate `mcp` functionality in various
documentation.

## See also

[`mcp_example`](https://lindeloev.github.io/mcp/dev/reference/mcp_example.md)
for the model and data used to create it, and
[`mcpfit-class`](https://lindeloev.github.io/mcp/dev/reference/mcpfit-class.md)
for the structure and methods of fitted models.
